# Find value in the valueless

**Find value in the valueless** is a lightweight Minecraft Fabric mod that gives more value to otherwise useless items.

为原版 Minecraft 增添一些实用的小改动，让原本用途有限的物品发挥更多价值。

## ✨ Features | 功能

### 1. Rotten Flesh to Leather | 腐肉烧炼成皮革

- Smelt Rotten Flesh into Leather using a furnace.
- Turn an otherwise unwanted item into a useful crafting material.

将腐肉放入熔炉烧炼，即可获得皮革，让平时容易堆积的腐肉拥有新的用途。

### 2. More Compostable Items | 增加可堆肥物品

- Adds additional compostable items using Fabric API.
- Make better use of items that would otherwise go to waste.

通过 Fabric API 为更多物品添加可堆肥属性，让资源利用更加灵活。

## 📦 Installation | 安装

1. Install Minecraft Java Edition.
2. Install Fabric Loader for a compatible Minecraft version.
3. Install Fabric API.
4. Download the mod `.jar` file.
5. Place the file in your Minecraft `mods` folder.

### 中文安装说明

1. 安装 Minecraft Java 版。
2. 安装兼容游戏版本的 Fabric Loader。
3. 安装对应版本的 Fabric API。
4. 下载本模组的 `.jar` 文件。
5. 将文件放入 Minecraft 游戏目录下的 `mods` 文件夹。
6. 启动游戏。
